# Банковское приложение
## Проект по реализации банковского приложения
**Проект умеет маскировать данные пользователя - номера карт и счетов, так же сортировать данные в виде списков по значениям ключей и по дате**

**Здесь должна быть инструкция по установке**


## Тестирование


### Назначение
Тесты проверяют:
- корректность маскировки номеров карт и счетов (`mask_account_card`);
- обработку крайних случаев (пустые строки, некорректные форматы);
- соответствие вывода ожидаемым шаблонам.


### Запуск тестов
Установите зависимости:

pip install -r requirements-dev.txt
